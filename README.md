## 💡 핵심 학습 내용

### Object 클래스

모든 Java 클래스는 Object 클래스를 상속받습니다.  
`toString()`, `equals()`, `hashCode()` 같은 메서드는 객체 비교와 출력에서 자주 사용됩니다.

### 불변 객체

불변 객체는 한 번 생성된 이후 내부 값이 변경되지 않는 객체입니다.  
데이터 안정성이 높고, 여러 곳에서 공유해도 안전하다는 장점이 있습니다.

### String 클래스

String은 Java에서 문자열을 다룰 때 사용하는 대표적인 클래스입니다.  
String은 불변 객체이기 때문에 문자열을 자주 변경해야 하는 경우에는 `StringBuilder` 사용이 더 적합할 수 있습니다.

### 래퍼 클래스

래퍼 클래스는 기본형 값을 객체처럼 다룰 수 있도록 제공되는 클래스입니다.  
예를 들어 `int`는 `Integer`, `double`은 `Double`로 감쌀 수 있습니다.

### 열거형 ENUM

Enum은 정해진 상수 집합을 타입 안전하게 관리할 수 있도록 도와줍니다.  
문자열 상수를 직접 사용하는 것보다 오타를 줄이고 코드의 안정성을 높일 수 있습니다.

### 날짜와 시간

Java의 날짜와 시간 API를 통해 날짜, 시간, 날짜와 시간을 객체로 다룰 수 있습니다.  
`LocalDate`, `LocalTime`, `LocalDateTime` 등을 학습했습니다.

### 중첩 클래스와 내부 클래스

클래스 안에 또 다른 클래스를 정의하여 관련 있는 코드를 논리적으로 묶을 수 있습니다.  
이를 통해 코드의 응집도를 높이고 구조를 더 명확하게 만들 수 있습니다.

### 예외 처리

예외 처리는 프로그램 실행 중 발생할 수 있는 오류 상황을 처리하는 방법입니다.  
`try-catch`, `throw`, `throws`를 사용하여 예외 발생 흐름과 처리 방식을 학습했습니다.
